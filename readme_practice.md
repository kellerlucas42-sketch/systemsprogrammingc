# README Template

This readme template is designed to help you practice good documentation skills.

## Description

When you publish code or work, especially when it is open-source, you want people to be able to test it themselves and make changes. A good README provides instructions and information about what a project is, what its purpose is, and how to use it.

To help people have easy access to the documentation in a project, whenever GitHub sees a file titled `readme.md` or `README.md` in the parent folder of a repository, it shows that file on front page (as you saw with the README file in this repository). Though you won't publish this file, its good practice for your second README which will be published alongside your code.

## Instructions


Remember to use proper markdown formatting. If you need help with markdown formatting, see the [Coding Standard](https://byu-cpe.github.io/ecen224/coding-standard/) page for help. There is also [this reference created by GitHub](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) as well as [this interactive markdown tutorial](https://www.markdowntutorial.com/).

There is a rubric attached to the assignement in Learning Suite. Do not forget to turn this assignment in! You get 50% credit just for turning it in with some progress (even 1 sentence).

Note: do not surround your markdown in backticks ``` like the example above. Those backticks preven the markdown from compiling.
