# ECEn 225 Starter Labs Repository

## Introduction

Welcome to ECEn 225! This README file will help you to learn about the first set of labs. These labs are designed to teach you to how to use Linux systems, how to work with your doorbell, and will teach you some C programming principles you will need when creating your doorbell software.

You will also practice writing some basic documentation by filling out your own README file describing what you did in each lab and how someone can replicate your work. A template mardown file is provided for you in this repository, titled `submission.md`.

To help you prepare for your labs during the second half of the semester, _you must do each of these labs while SSH'ed into your Pi_. The [Getting Started](https://byu-cpe.github.io/ecen224/labs/01_getting-started/) page has instructions if you need them.

## Using This Repository

You should have already built your Raspberry Pi's by now. If you haven't, go follow the instructions on the [Getting Started](https://byu-cpe.github.io/ecen224/labs/01_getting-started/) page of the classroom website to build your Raspberry Pi and prepare it to work on your labs.

Once you are ready, clone this repository onto your Raspberry Pi. To do this, follow the instructions on the page dedicated to [Using Github](https://byu-cpe.github.io/ecen224/lab-setup/).

Within this repository are the following labs:

- **Lab 02: Command Line**: Practice working with Linux systems, and navigating your doorbell.
- **Lab 03: C Programming Part-1:** Some introduction to reading, writing, and compiling C code.
- **Lab 04: C Programming Part-2:** Introduction to data types, strings, and more C topics.
- **Lab 05: Image**: Some more advanced data manipulation practice.

Each of these labs has a page on the classroom website that details how they should be done.
